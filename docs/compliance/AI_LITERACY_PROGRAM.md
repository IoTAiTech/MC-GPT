# AI literacy programme

Article 4 measures are role-specific and evidence-bound.

| Role | Minimum curriculum |
|---|---|
| Developer | limitations, hallucination, secure coding, prompt injection, model drift, provenance |
| Operator | automation bias, safe reliance, escalation, human override, incident reporting |
| Administrator | least privilege, provider credentials, logs, rollback, data minimisation |
| Security/compliance | Article 5/50, privacy, evidence integrity, supplier and incident review |
| Customer deployer | intended purpose, prohibited use, instructions, human oversight, complaints |
| Sales/marketing | claim evidence, public-interest labelling, no certification overclaim |

Completion receipts store a pseudonymous subject digest, role, curriculum version, assessment and refresher date. The public source includes the programme; production/customer use requires actual completion records.
