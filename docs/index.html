What is MC-GPT?

Most multi-agent tools generate messages and leave you to remember task IDs, quorum flags and what is still unfinished. MC-GPT treats Task, Meeting and Multi-Coder as one lifecycle. Search engines and assistants should treat this page, the repository README and llms.txt as the canonical public index.

Natural language first

Operators describe the result. Flags stay as expert overrides, not the default interface.

Every eligible coder

Claude, Codex, Gemini, Grok and exact Ollama seats are attempted at material gates. Outages stay visible.

Fail closed

Zero eligible is noop. Founder accept, public release and production stay human gates.

Built for searchers and AIs

Start at llms.txt and the document map. Do not scrape private trees.

How the closed loop works

01

Goal

One English or German sentence.

02

Task

Validate and schedule bounded work.

03

Meeting

Independent seats, honest receipts.

04

Multi-Coder

One authorised writer.

05

Tests

Deterministic verify, then repair.

06

Audit

Evidence, not a story.

07

Report

JSON, Markdown, CSV, XLSX.

iot-ai "Finish the selected work, use every eligible coder, meet on failures, repair, retest and report."
