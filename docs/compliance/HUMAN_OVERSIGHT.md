# Human oversight

- Technical completion never equals founder/customer acceptance.
- Required roles must accept one frozen plan digest before implementation.
- Task writes require scope, Work Unit and lease controls where task execution is used.
- High-risk candidates remain blocked until classified.
- Human override preserves the original model/synthesis evidence and records reason, scope and residual risk; it does not rewrite a blocked AI decision into consensus.
- Operators can stop, reject, reverse or roll back material changes.
