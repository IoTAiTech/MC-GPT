# Settings

```bash
iot-ai settings show
iot-ai settings group all-cloud off
iot-ai settings group ollama on
iot-ai settings profile set ultracode --session-only
```

The `ultracode` profile uses xhigh reasoning only for architecture, root-cause, security and final adjudication; deterministic and mechanical nodes remain lower effort.
