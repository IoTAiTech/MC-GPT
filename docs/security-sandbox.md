# Security and Sandbox

Agent nodes receive read/write scopes and resource claims. Write-capable work should use isolated worktrees or exclusive path leases. Provider output is untrusted. Public export forbids symlinks, traversal, secrets, private infrastructure, private histories and Enterprise source.
