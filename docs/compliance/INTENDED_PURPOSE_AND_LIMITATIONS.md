# Intended purpose and limitations

## Intended purpose

IOT-AI helps a human developer or technical team analyse a software-engineering goal, reuse validated knowledge, assign immutable specialist roles, query eligible coder/model seats, challenge proposals, freeze a plan digest, execute authorised work, run deterministic tests, produce evidence and submit technical completion for human decision.

## Explicitly excluded

- employment, worker monitoring, performance ranking or hiring decisions;
- medical diagnosis, treatment, emergency triage or eligibility decisions;
- law-enforcement, migration, asylum or judicial decisions;
- credit, insurance, public-benefit or essential-service eligibility;
- social scoring, manipulative persuasion or exploitation of vulnerable persons;
- biometric identification/categorisation or workplace/education emotion recognition;
- autonomous safety-critical or critical-infrastructure control;
- publication of unlabelled deepfakes or public-interest AI text lacking the required editorial control/label.

Using the Suite outside this purpose invalidates the current classification and requires a new system card and release/deployment gate.
