# iot-ai-tasks

Use `iot-ai tasks ...` as the canonical command.

Before claim, run, go, execute or solve-all, the task-validation gate asks whether specialist coders and eligible model-specific Ollama Cloud seats should validate and optimise the task. No lease or write occurs until the user chooses.
