# iot-ai-status

Status must answer:
1. What was requested?
2. What is complete?
3. What is currently running?
4. Which tasks are awaiting Founder?
5. Which tasks are externally/authority/safety blocked?
6. Which providers/models contributed or failed?
7. What evidence and tests exist?
8. What will the autonomous loop do next?

Do not report `pass` for zero eligible work, progress-only heartbeats, single-model review or audit-failing submissions. Show exact log/report/checkpoint paths.
