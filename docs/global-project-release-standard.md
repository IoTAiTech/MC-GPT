# IoT-AI.Tech Global Public/Commercial Release Standard

Every IoT-AI.Tech project must resolve its license from a project-specific policy; missing policy blocks release. Public export is generated from an allowlist into unrelated Git history. Enterprise implementation, customer data, internal evidence, private addresses and credentials never enter public history. Every release includes install/verify/repair/upgrade/uninstall/rollback, tests, SBOM, manifest, SHA-256, security scan and documentation.
