# Quickstart

Describe the result, not the internal flags:

```bash
iot-ai "Finish the selected tasks, use all eligible coders, meet on failures, repair, retest and report until terminal."
```

Read-only example:

```bash
iot-ai "Review the remaining tasks and show one brief management report; do not execute."
```

Continue from the saved conversation checkpoint:

```bash
iot-ai "Continue the rest and finish everything that is safely executable."
```

Advanced Task, Meeting, Multi-Coder and Mesh commands remain available for diagnostics only. See `autonomous-closed-loop.md`.
