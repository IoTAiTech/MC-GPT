# Quickstart

```bash
iot-ai help
iot-ai settings show
iot-ai status
iot-ai settings group all-cloud on   # explicit cloud opt-in
iot-ai "Review the design and return an evidence-bound plan"
```

`iot-ai status --live` performs provider calls and may consume subscription/API quota.
