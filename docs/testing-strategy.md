# Testing Strategy

Release gates include compile, unittest, pytest, graph semantics, Ollama first-class routing, privacy/redaction, public-boundary scan, PEP-668 installation, normal rollback, deterministic dual build and package extraction verification. External gates are never marked pass without the real target.
