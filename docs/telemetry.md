# Telemetry and Reports

Each provider contribution records provider, role, stage, requested/served model, request ID, tokens when reported, latency, status, failure class, fallback and rubric-based quality. Null means unavailable; missing values are never converted to zero. Reports support 1, 3, 7, 14, 30, 90, 180 and 365-day windows. Raw prompts and outputs are disabled by default.
