# Post-market monitoring

The public Developer Preview defines a monitoring process; it does not claim a live customer post-market system.

Monitor at least:

- provider/model drift, authentication, quota and fallback;
- empty/meta-only contributions and false acceptance;
- test, security, rollback and diagnostics failures;
- Article 5/50 control failures;
- unsupported public claims and data-boundary violations;
- customer complaints, incidents and substantial modifications.

For each production deployment, define owner, sources, thresholds, review interval, affected persons/assets, complaint route, evidence retention, corrective action and withdrawal/disable procedure.
